Linux Foundation Certified System Administrator（LFCS）試験に向けた、体系的かつ実践的な学習パスです。主要ディストリビューションにおける実務的な Linux 管理、パフォーマンスベースのタスク、現実のシナリオに焦点を当てます。LFCS コース、ラボ、模擬試験の演習は順次追加され、LFCS の目標に沿ったスキルを育成します。

## 実践しながら学ぶ
